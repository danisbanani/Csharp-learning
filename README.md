# Csharp-learning
A collection of my personal C# projects and practice exercises as I build and improve my programming skills.
# Projects
### 1. Guess the number - console-based guessing game.
-**Features**
>Three difficulty levels (Easy: 1-50, Normal: 1-100, Hard: 1-1000).
>Input validation using `int.TryParse` to prevent crashes.
>Built-in `Stopwatch` to track how many seconds it took to guessing the number.
